# Security policy

skillbook holds agent skills: markdown instructions, templates and a few scripts. A security problem here is anything that could make an agent following a skill harm the person using it or their repositories: an instruction that leaks a secret, a template that weakens a repository's security, a script that runs untrusted input.

## Supported versions

The latest release only.

## Reporting

Report privately through GitHub's private vulnerability reporting: the "Report a vulnerability" button on this repository's Security tab. Please do not open a public issue.

Include the skill and file, the agent and its version, what happens, and how to reproduce it.

## What to expect

- An acknowledgement within 7 days.
- A fix, or a decision not to fix with the reason, within 60 days.
- Disclosure once a fix is released, or after 90 days at the latest, agreed with you.
- Credit in the release notes, unless you prefer otherwise.
