# respond-explain

Clears up something the agent itself said that did not land.

## Instructions

1. Explain it in the shape that the `respond` skill's rule on an explanation gives. Put the point in one plain sentence. Give the example only when the point is abstract.
2. Replace every reference the person cannot resolve with what it means.
3. Stop once the point is made. Close by naming what could be explained further, without a question. The person's next message shows whether it landed.
4. If asked to explain more, go one level deeper, on the piece asked about only, not on everything.

## The last instruction

You are done when every term and reference in the explanation is one the person knows or one it explains, and nothing is there that the point does not need.
