# respond-explain

Clears up something the agent itself said that did not land.

## Instructions

1. Explain it in the shape `respond`'s rule on an explanation gives, with the point in one plain sentence and the example only when the point is abstract.
2. Replace every reference the person cannot resolve with what it means.
3. Stop once the point is made, and close by naming what could be explained further, without a question; whether it landed, the person's next message says.
4. Asked to explain more, go one level deeper, on the piece asked about only, not on everything.

## The last instruction

Done when every term and reference in the explanation is one the person knows or one it explains, and nothing is there that the point does not need.
