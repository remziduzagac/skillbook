# organize-compose

## Purpose

Adds a parent that states what selected items share, keeping their content unchanged.

## When to use

Use when selected items need a parent that explains what they share. For example, selected files may belong under a folder with a useful shared purpose.

## When not

- Sorting every item into groups: use the `organize-split` guide. Compose adds a parent for selected items.
- Only finding items: use the `organize-cluster` guide. A navigation view needs no new shared parent.

## Gives back

The new parent, what the selected items share, and where those items belong. Their content stays unchanged.

```text
A B C → P over A, B, C
```

## Instructions

Add a parent that explains what selected items share. The parent should earn its place by saying something useful while leaving each item’s content intact. **Find the shared statement, test whether a parent helps, then propose its boundary and placement.**

1. **Find what the selected items share under the `organize` guide.** A parent based only on a vague theme adds a level readers must open without learning anything.
   - Look at the selected items' purposes and content. Keep this distinct from sorting the whole collection.
2. **Require at least two items and a useful shared statement before adding the parent.** A redundant parent adds navigation cost for every reader.
   - Check it says something no item says alone. If it does not, add no parent.
3. **Name the parent and give its one-sentence boundary by the `organize` guide.** A broad or unclear parent can pull unrelated items into the arrangement.
   - Say what belongs and what does not, in the parent itself, such as its README or opening note, so a later reader can place a new item. Follow the `understand` guide's who-decides rule for the name and the choice of parent.
4. **Prepare where each selected item goes, for the `organize` guide's map.** Moving beyond the selected set can disturb work the user did not ask to rearrange.
   - Include every selected item that belongs and no other item. Leave unselected items where they are, and keep every item's content.
   - Where folders hold the arrangement, such as files in a folder tree, map the selected items to move under the parent.
   - Show the map and end the turn first when the `organize` guide's rule 4 needs approval.
5. **Check the parent and “Gives back” before returning.** Always do this last. A new heading alone does not show that the arrangement is useful or preserved.
   - Check the shared statement, useful parent, boundary and each selected item's place. Fix lost content or unrelated placements before returning.
   - Return the proposed or approved parent with inventory evidence. After applying, return the checked result to the `organize` guide's step 6, which asks the user to confirm it.
