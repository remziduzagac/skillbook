# understand-clarify-deep

Questions a part, or a whole plan, until nothing in it is left assumed: numbered rounds, each question with a recommended answer where there is a basis, going down level by level.

## Rules

1. **A question that depends on an unanswered one waits** for a later round, because that answer may change it. Each round asks what can be answered now. This is an order to ask in, with nothing to draw or keep.
2. **Level by level:** at each new level inside the part, first see that level whole through `understand-clarify-shallow`, then go down. A skipped level leaves its parts assumed.
3. **The user confirms the summary before anything is acted on.** The summary lists what is decided, parked, accepted and assumed, with parked and assumed as `respond-ask` defines them.
   - If the user stops early, every open question goes into the summary as an assumption, and you show the summary before acting.
   - Where the user has already said to go on, showing it is enough, because nothing assumed is then acted on unseen.
4. **Never record unasked:** recording writes to the project, and the `act` skill's rule is to do exactly what was asked.

Facts and decisions follow understand's rules: you find the facts, and the decisions are the user's. Put rounds and take answers as `respond-ask` says. After each round, wait as `understand-clarify-shallow` says. In the summary, list as accepted the recommended answers that "go ahead" accepted before the end.

## Advice

- Let the answers shape the next round.
- In a long session, offer to record the decisions so far, so that compaction cannot lose them. Where to record them:
  - where the caller keeps them;
  - used directly, with no caller: where the loaded keeper says;
  - with no keeper: in a file the user names.

You are done when no level is left with anything assumed that would change the work, and the user has confirmed the summary, or seen it where they said to go on.

## The last instruction

Before you act on anything: the user has confirmed the summary, or you showed it where they said to go on, and you hand it back in understand's result shape.
