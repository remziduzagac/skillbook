# Code as a source

Use this guide when reading source code to answer how something behaves. Read only the relevant paths and their callers or tests. Record the path and line, and the applicable revision or version where it matters.

Separate what you read from what you ran. A branch in code is not proof that it ran in this environment. Use a permitted reproduction when execution would settle the fact more surely. Keep probes temporary under the parent and the `act` skill.

When access or execution is missing, return the readable evidence and the unobserved behavior. Do not invent a run or inspect another repository outside the authorized scope. The parent owns provenance and the finding's applicability.
