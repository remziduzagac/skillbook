# Docs

One page per main skill, written for people: what it does, when to reach for it, where it fits, common questions, and how to tell it is working. Essentials' page is also the map of its groups and the skills under them, which the main skill does not carry, since it is read every turn (D183). The pages come with the skills; none exists yet.
