# skillbook documentation

skillbook is a book of skills for AI agents such as Claude Code and Codex: instructions an agent loads to understand what you want, do the work with care and tell you plainly what it did. The skills come in sets, each installed on its own. Essentials is released; the other sets are still being designed.

The [documentation website](https://remziduzagac.github.io/skillbook/docs/) has the same pages with search. What each release changed is in the [changelog](../CHANGELOG.md).

## Start here

- [Installing skillbook](install.md): install a set with one line, set up your agent, check the files, update, try a preview and remove it.
- [Essentials](essentials/README.md): what essentials is for, how it works, and a line on each of its guides.

## The sets to come

- [blueprint](blueprint/idea.md): the first idea of the blueprint method, with a worked example that follows one feature through it.
- [softeng](softeng/idea.md): the first idea of the softeng set, for designing, building, testing, reviewing, shipping and maintaining software.
- [authoring](authoring/idea.md): the first idea of the authoring set, for documentation, business documents, articles and issues written for people.
- [cadence](cadence/idea.md): the first idea of the cadence set, for meetings, tasks and daily and weekly reviews.
- [compendium](compendium/idea.md): the first idea of the compendium set, for capturing, distilling and finding what you learn.
