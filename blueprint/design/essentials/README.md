# essentials

What any work needs: the set every other set builds on, its main skill loaded first for any request (D152, D154, D164).

- [essentials.md](essentials.md): the main skill: its rules, delegation by default, one line per group, the wrap-up offer.
- [conduct.md](conduct.md): how the agent behaves in every response: respond, layout, act, ask, explain, stakes, guardrails, verify, rightsize with lean and enrich, cleanup.
- [understand.md](understand.md): understanding before acting: discuss, clarify, frame, brainstorm, weigh, challenge, argue, naming, research.
- [organize.md](organize.md): arranging things with boundaries: split, merge, compose, normalize, cluster.
- [coordinate.md](coordinate.md): working with agents not in this conversation: delegate, brief, carryover, instruct, setup, learn.
- [devise.md](devise.md): deciding what the work will be and its steps: design, with its review, and plan.

Ideas not yet decided are in [../../ideas/](../../ideas/README.md), one file per group.
