# Design

How skillbook and its skills work. The initial design is open (D27): changes go straight into these files.

- [skillbook.md](skillbook.md): how the repository is organised, how skills load, install and are maintained, and the writing rules every skill follows.
- [blueprint.md](blueprint.md): the blueprint method, specified for the blueprint skill.
- [blueprint-example.md](blueprint-example.md): one feature followed through every part of a blueprint.
- [greenrepo.md](greenrepo.md): the greenrepo standard, specified for the greenrepo skill.
- [greenrepo-profiles.md](greenrepo-profiles.md): greenrepo's profiles for languages, tools and platforms.
