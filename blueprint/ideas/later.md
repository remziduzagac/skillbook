# Ideas: the later sets

The sets set aside for later, each to be installed on its own once designed: rigs, a knowledge base and routines (D64, D103, D152, D167). Nothing in this file is decided unless it cites a decision. Their skills are listed as ideas, each with the sources that hold material for it; "(an idea)" marks one with none worked out yet. What was known about the knowledge base and routines when they were set aside, decided and not, is in [../notes/knowledge-and-routines.md](../notes/knowledge-and-routines.md), where their design starts.

## rigs

The programs agents drive: git and the GitHub CLI, other agent programs for delegation, terminal multiplexers, editors and containers; one home per program for coordinate's delegate and setup (D103). (an idea)

## A knowledge base

What is known, in plain files; the set's name waits for the private notes system (D152).

- **capture:** get it down now, sort it later (the private notes system, slipbox, a private agent-workflow project, alirezarezvani/claude-skills).
- **ingest:** keep the source first, card it, extract from it (the private notes system, the private agent-workflow project).
- **distill:** atomic insights linked back to their sources (the private notes system, the private agent-workflow project).
- **find:** search lenses and topic briefings (the private agent-workflow project, slipbox, two private documentation systems).
- **tidy:** links, orphans, frontmatter, tags (slipbox, the two private documentation systems).
- **vault:** set up or reorganise a notes folder or a notes-app vault, an idea (the private notes system, slipbox).
- **teach:** learn a topic over several sessions (mattpocock/skills).

## Routines

The person's daily work: meetings, reviews, tasks (D152).

- **meetings:** decisions and actions with owner, due date and a quote; hands notes to the knowledge base's capture (the private agent-workflow project, the private notes system).
- **reflect:** daily, weekly and monthly reviews; chronicles (the private notes system, slipbox, gstack, alirezarezvani/claude-skills).
- **close-out:** keep what matters, wrap up, clean, retire; hands over to distill, to coordinate's carryover and to coordinate's learn (the private agent-workflow project, the private notes system).
- **tasks:** personal tasks: parents, waiting or blocked, today, an idea (the private notes system).
- **triage:** incoming issues turned into agent-ready briefs, as a routine, an idea (mattpocock/skills, gstack).
- **focus:** a focused work session, an idea (alirezarezvani/claude-skills).
- **people:** one-to-ones, hiring rubrics, onboarding, feedback, an idea (the private agent-workflow project).
